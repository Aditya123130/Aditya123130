## Featured project

### [PulseBridge Community](https://github.com/Aditya123130/PulseBridge-Community)

An open-source research toolkit for ESP32-to-Linux/Raspberry Pi USB/UART communication, Protocol 3 validation, and reproducible experiments.

- [Source and setup](https://github.com/Aditya123130/PulseBridge-Community)
- [Project wiki](https://github.com/Aditya123130/PulseBridge-Community/wiki)
- [Hardware validation notes](https://github.com/Aditya123130/PulseBridge-Community/blob/main/docs/HARDWARE_VALIDATION.md)
